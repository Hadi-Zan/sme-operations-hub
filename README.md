# SME Operations Hub

A simple operations workspace for small service businesses. The Phase 1 interface uses sample data only and establishes the dashboard shell, navigation, and front-end conventions for later development.

## Current scope

- Responsive dashboard shell
- Navigation for Dashboard, Tasks, Inventory, Customers, Follow-ups, and Settings
- Placeholder routes and clearly labelled demo data
- No database, authentication, messaging, payments, automations, or external integrations

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- npm

## Local development

Install Node.js 24 LTS, then run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```
